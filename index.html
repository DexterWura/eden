Eden – Setup

If you see this page, the server is serving from the project root but index.php is not running (or the server is showing this static file first).

  • Set your domain’s document root to this folder (the one that contains index.php, core/, and this file).
  • Ensure PHP runs for .php files (e.g. PHP 8.2+ handler in cPanel).
  • Then run in the core folder: composer install --no-dev.
  • Open /install to run the web installer.

Test: /ok.php (should show “OK” if PHP works).
