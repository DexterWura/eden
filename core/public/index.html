Eden – Setup

If you see this page, the server is serving from core/public but index.php is not running.

  • Ensure PHP runs for .php files (e.g. PHP 8.2+ in cPanel).
  • Run in the core folder (parent of this folder): composer install --no-dev.
  • Open /install to run the web installer.

Test: /ok.php (should show “OK” if PHP works).
